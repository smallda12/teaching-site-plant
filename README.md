## 🔒 學生個資

**這個 repo 不包含任何學生資料。**

點名功能的學生姓名與照片**只存在使用者自己瀏覽器的 localStorage / IndexedDB**，
不會寫入任何檔案、不會上傳、也不會進入版本控制。

網站會自動判斷執行環境：

| 開啟方式 | 版本 | 行為 |
|---|---|---|
| 本機雙擊 `index.html`（`file://`） | 教室版 | 點名區可上傳學生照片，資料只留在該台電腦 |
| 線上網址（`https://`） | **公開版** | **照片上傳功能自動關閉**，只保留文字輸入 |

也就是說，線上這一版本身就無法建立含照片的名單。

## 技術

純 HTML / CSS / JavaScript，無框架、無建置流程、無外部相依。

- 圖片：WebP（62 頁簡報 + 20 張圖卡）
- 語音：98 支 MP3，由 edge-tts 以 `zh-TW-HsiaoChenNeural` 產生（語速 -25%）
- 響應式：三層斷點，涵蓋大螢幕電腦、教室電腦、平板、手機（含橫躺）
